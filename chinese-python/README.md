# 中文编程 · 用中文写 Python

在浏览器里用中文编写 Python 程序：左侧列出全部可用的**中文积木**，输入时自动弹出提示，右侧**实时翻译**成标准 Python 代码。

## 快速开始

- 直接双击打开 `index.html` 即可使用（纯网页，无需安装、无需联网）
- 或者运行 `python -m http.server` 后访问 `http://localhost:8000`

## 使用方法

1. 在中间的「中文代码区」输入中文代码，或点击左侧积木直接插入
2. **每个积木都带完整模板**：点击后自动填入格式并选中第一个待填部分（如 `打印(@@内容@@)`），填完按 **Tab** 自动跳到下一处待填，不用再管括号和参数顺序
3. 输入时自动弹出候选积木，↑↓ 选择、回车/Tab 插入
4. 右侧实时显示翻译出的 Python 代码，可「复制」或「下载 .py」
5. 写错时会在右侧给出中文错误提示并标注行号
6. 顶部下拉框可载入内置示例（画五角星、猜数字等）

| `打印("你好")` | `print("你好")` |

| `令 x = 5` / `x 等于 5` / `x = 5` | `x = 5` |
| `如果 条件：` / `否则：` / `否则如果 条件：` | `if:` / `else:` / `elif:` |
| `当 条件：` | `while 条件:` |
| `重复执行 5 次：` | `for _循环0 in range(5):` |
| `重复执行直到 条件：` | `while True: … if 条件: break`（先执行后判断） |
| `遍历 x 在 范围(5)：` | `for x in range(5):` |
| `定义 函数名(参数)：… 返回 值` | `def 函数名(参数): … return 值` |
| `类 名称：` + `定义 初始化(自己)：` | `class 名称:` + `def __init__(self):` |
| `自身.属性` | `self.属性` |
| `尝试：… 捕获 值错误 作为 错误：… 最后：…` | `try: … except ValueError as 错误: … finally: …` |
| `使用 资源 作为 名字：` | `with 资源 as 名字:` |
| `抛出 值错误("信息")` / `断言 条件` | `raise ValueError("信息")` / `assert 条件` |
| `删除 x` / `传递` / `生成 值` | `del x` / `pass` / `yield 值` |
| `全局 x` / `非局部 x` / `异步 定义` / `等待` | `global x` / `nonlocal x` / `async def` / `await` |
| `值 如果 条件 否则 另一个值` | `值 if 条件 else 另一个值` |
| `[表达式 对于 x 在 列表 如果 条件]` | `[表达式 for x in 列表 if 条件]` |
| `a 位与 b 位或 c` / `1 左移 2` | `a & b \| c` / `1 << 2` |
| `断` / `继续` | `break` / `continue` |

## 反向翻译（Python → 中文）

右侧面板点「反向翻译」标签：把 Python 代码粘贴进去，自动翻译成中文，支持：
- 语句还原：`if/elif/else` → `如果/否则如果/否则`、`while` → `当`、`for ... in range(n)` → `遍历 ... 在 范围(n)`、`def` → `定义`、`class`/`__init__(self)` → `类`/`初始化(自己)`、`try/except/finally` → `尝试/捕获/最后`、`with ... as` → `使用 ... 作为`、`lambda` → `匿名函数`、`is/is not` → `是/不是`、`a, b = f()` → `a，b = f()`
- 名称还原：`print` → `打印`、`math.sqrt` → `平方根`、`random.randint` → `随机整数`、`lst.append` → `lst.追加`、`r.text` → `r.获取文本`、`ValueError` → `值错误`、`import urllib.request` → `引入 网络`
- 高阶语法：f-string、三引号多行字符串（转成单行 `\n`）、import as 别名、关键字参数、默认参数、类型标注（自动忽略）、多变量 for、多返回值、调用后下标链（`resp.json()["data"][0]`）、切片（`text[:200]`）、列表/字典跨行字面量、相邻字符串拼接、元组 except 类型、中文变量名
- 注释完整保留：独立注释、行内注释、块头注释原样往返
- 点「应用到编辑器」把中文代码写入代码区，可继续用中文修改；与正向翻译可互相往返（`node test.js` 含往返一致性测试与 `sample-ai.py` 完整程序回归）

## 数据窗口（变量与数据）

点右上角「数据窗口」可打开/关闭一个独立的小窗口（可拖动、可记住开关状态）：

- **变量与数据**：实时列出代码里的每个变量，显示推断出的**类型**（整数/小数/文本/布尔/列表/字典…）、值的中文写法、以及**来源**（来自输入 / 来自函数 / 计算得出 / 直接赋值），点击任意一行即可把变量名插入到光标处
- **函数返回**：列出每个函数及其返回值（`加法(a, b) → 返回 a 加 b`），点击即可插入调用
- 左侧积木面板还有「变量」分类，把当前变量变成可点击的积木；输入时也会补全变量名

## 默认支持的库（左侧「库·」分类）

| 中文名 | Python 库 | 示例积木 |
|---|---|---|
| 数学 | math | 平方根、次方、正弦、圆周率 |
| 随机 | random | 随机整数、随机选择、打乱 |
| 时间 | time | 睡眠、当前时间 |
| 日期时间 | datetime | 现在、日期 |
| 系统 | os | 列出文件、创建目录、路径连接 |
| 数据格式 | json | 转为文本、读取文本 |
| 海龟绘图 | turtle | 前进、右转、画圆、设置颜色、完成 |
| 窗口界面 | tkinter | 创建窗口、标签、按钮、主循环 |
| 网络 | urllib.request | 打开网址、获取网页内容、创建/发送请求、提交表单、下载文件 |
| 网址编码 | urllib.parse | 编码网址、解码网址、参数编码 |
| 网址解析 | urllib.parse | 解析网址（方案/主机/路径/查询）、合并网址、组装网址 |
| 网络请求 | requests | 请求获取/发送/放置/删除/补丁、创建会话、带头部/超时/表单/JSON 的请求 |

响应数据的用法：`响应 = 请求获取("网址")` 后可用 `响应.获取文本`、`响应.状态码`、`响应.头部`、`响应.JSON内容`、`响应.原因` 等属性；`部分 = 解析网址(...)` 后可用 `部分.方案`、`部分.主机`、`部分.路径`、`部分.查询` 等。
错误处理：`尝试：` 后用 `捕获 值错误 作为 错误：`（错误类型积木在「错误」分类，如 网络错误 → urllib.error.URLError）。

## 积木分类

全部 / 变量 / 逻辑 / 数据 / 列表 / 文本 / 运算符 / 进阶 / 错误 + 每个库一个分类：
- **变量**：令（赋值）、增加、减少、删除、全局、非局部 + 已声明变量的实时列表（点击插入）
- **逻辑**：打印、输入、如果/否则如果/否则、当、遍历、定义、返回、断、继续、注释、引入
- **数据**：创建列表、创建字典、类型转换、长度/范围/求和/排序、进制与字符转换、格式化、真/假/无
- **列表**：取元素、追加、移除、弹出、插入、清除、反转、排序、扩展、查找索引、元素数量、复制
- **文本**：取字符、分隔、连接、替换、大小写、查找、判断、居中、编码解码
- **运算符**：算术、比较、且/或/非、属于、是/不是、位运算
- **进阶**：类、初始化、自身、尝试/捕获/最后、使用、抛出、断言、传递、生成、异步、条件选择、推导式
- **错误**：13 种错误类型（配合抛出/捕获）

**每个积木的模板都带示例占位**：如「打开网址」插入 `打开网址("https://example.com")`、「请求发送」插入 `请求发送("https://example.com", {"关键词": "你好"})`、「删除文件」插入 `删除文件("要删除的文件.txt")`、「取字符」插入 `@@文本@@[@@位置@@]`——插入后自动选中示例内容，直接输入即替换，按 Tab 跳到下一处。
用 `node check-templates.js` 可自动验证全部积木模板插入后都能直接翻译。

直接写库函数名也可以（如 `随机整数(1, 100)`），翻译时会自动补上 `import`。

## 项目结构

```
chinese-python/
├── index.html          # 主页面（积木面板 + 中文编辑器 + Python 翻译区）
├── css/style.css       # 样式
├── js/
│   ├── libraries.js    # 常用库的中文映射表（可自行扩展）
│   ├── blocks.js       # 逻辑/数据/运算符积木数据
│   ├── lexer.js        # 词法分析器
│   ├── parser.js       # 语法分析器（语法树）
│   ├── generator.js    # 生成 Python 代码
│   ├── examples.js     # 内置示例程序
│   └── editor.js       # 编辑器、自动提示、实时翻译
├── examples/           # 示例程序文本（与内置示例一致）
├── test.js             # 翻译器测试（node test.js）
└── README.md
```

## 扩展新的库积木

打开 `js/libraries.js`，在 `LIBRARIES` 数组里按同样格式添加即可：

```js
{ name: '网络', module: 'urllib.request', blocks: [
    { name: '打开网址', target: 'urlopen', desc: '读取网页内容' },
] }
```
